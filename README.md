# GorodPay

Промостраница приложения GorodPay для пассажиров.

Проект реализован на HTML, SCSS/Sass и vanilla JavaScript.

<!-- Скриншот проекта: ./docs/screenshot.png (файл пока отсутствует). -->

## Быстрый старт

Откройте `index.html` в браузере. Сборка не требуется: страница подключает готовый `style.css`.

## Стек

- HTML — разметка страницы.
- SCSS/Sass — стили и partial-файлы с переменными и настройками.
- Vanilla JavaScript — запуск анимации при готовности DOM.
- `images/sprite.svg` — SVG-спрайт иконок.

## Возможности

- Главный экран с анимированным появлением иллюстрации, заголовка, текста и кнопок.
- Выпадающее меню с переходами; открытие предусмотрено при наведении и фокусе клавиатуры.
- Анимация появления шапки и подвала.
- Настройки таймингов и геометрии анимаций вынесены в SCSS.
- Для пользователей, предпочитающих уменьшенное движение, предусмотрен режим `prefers-reduced-motion`.

## Структура проекта

| Путь | Назначение |
|---|---|
| `index.html` | HTML-разметка страницы. |
| `style.css`, `style.css.map` | Готовые стили и карта исходников. |
| `scss/` | Исходные SCSS-стили. |
| `scss/blocks/` | Стили блоков страницы. |
| `scss/global/` | Общие стили, миксины, анимации и настройки. |
| `js/main.js` | Запуск анимации страницы. |
| `images/`, `images/sprite/` | Изображения и отдельные SVG-иконки. |
| `images/sprite.svg` | SVG-спрайт. |
| `fonts/` | Файлы шрифта. |
| `LICENSE` | Лицензия проекта. |
